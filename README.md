# Soroban-learning-


A practical collection of Rust and Soroban smart contracts built while exploring the Stellar ecosystem.

## 🎯 Purpose

This repository documents my hands-on learning with Soroban and Rust through small, focused projects and experiments.

## 🛠️ Technologies

- Rust
- Soroban SDK
- Stellar
- Git & GitHub

## 📚 Topics Covered

- Smart contract fundamentals
- Contract storage
- Authentication
- Token interactions
- Error handling
- Testing
- Authorization patterns
- Secure contract development

## 🧪 Testing

Each project is tested where applicable using Rust's testing framework and Soroban testing utilities.

## 📁 Repository Structure

Projects are organized by topic, with each example kept small and focused on a specific Soroban or Rust concept.

## 🚀 Goal

The goal of this repository is to build practical experience with Rust and Soroban while developing clean, tested, and maintainable open-source code.

## 📌 Status

Actively maintained and updated as I continue learning and contributing to the Stellar ecosystem.
